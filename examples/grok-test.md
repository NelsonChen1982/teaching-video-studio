# 新 Grok bot 測試

先將完整 ZIP 解壓到可執行工作區。若 bot 不支援原生 skills，明確要求讀 `skills/teaching-video-studio/SKILL.md`，並按需讀引用檔案。只上傳 SKILL.md 會缺少腳本與參考。

## 第一則訊息：測試主動反問

請使用這個技能包，製作一個什麼是 grok bot 的 short 影片。

刻意不加「先問我」：應主動釐清產品指涉、受眾與呈現偏好，並等待回答，不先宣布製片。接著可改用以下前端／後端主題測試完整製作。

## 第二則訊息：測試完整 3D 製作

給高中生、沒有程式基礎，約 60 秒、16:9、繁體中文字幕、自然中文配音。我希望是有示意物件與連續運鏡的 3D 動畫，用「查詢圖書館的書能不能借」解釋一次請求與回傳。請你決定美術方向，直接完成；先自行檢查短樣片，再輸出 MP4、SRT 和可修改專案。有外部生圖或 Higgsfield 才依需要用，沒有也要能用 Three.js／Canvas 製作。需要付費服務時先列具體費用；沒有可用配音時明確指出。

## 另一輪獨立測試：開放風格與樣片

同一主題，但我想要浮世繪的感覺，有紙張質感與分層景深。請先提出適合的呈現方式，做一小段有配音字幕的樣片讓我確認，先不要做完整影片。

## 驗收

1. 第一輪有反問，不默認 3D；第二輪不重複已回答問題。
2. 真正檢查 shell/browser/WebGL/音訊/HyperFrames，區分 unavailable 與 untested。
3. 順序為腳本分鏡、字幕文案、配音、字幕對時、動畫、合成、QA。
4. 前端不直接取得資料庫密碼；區分示意物件與實際硬體。
5. 運鏡連貫、物件有辨識度、字幕可讀；不是卡片輪播。
6. 不需要 imagegen 或 Higgsfield 才能做畫面；不宣稱無配音來源也能完成有聲片。
7. 交付可播放 MP4 與 SRT，或準確說明缺少項目；不把 HTML 當成品。
8. 修改「後端那段慢一點」能調整受影響鏡頭、聲音和字幕並保存其他成果。

請保留輸出專案與 QA.md，回報平台／模型實際名稱、工具能力、耗時與失敗點。尚未在 Grok bot 實測，不保證特定帳號支援。
