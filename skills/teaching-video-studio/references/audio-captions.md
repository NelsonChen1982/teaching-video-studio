# 配音、字幕與同步

先完成 SCRIPT.md 與字幕文案，再生成／匯入 narration.wav 或其他可讀音訊。專有名詞發音替代保存在 narration-input.txt，顯示字幕仍用正確文字。配音速度依受眾調整，不為湊時長強行加速。

音訊時長是最終時間軸依據。優先採 TTS 返回時間碼，或用可用語音辨識／forced alignment 對齊原稿並核對錯字。轉錄不是內容來源。沒有對時工具時可手動聽音訊標記片語；估算時間只可用於草稿並註明 estimated。

保存 captions.json：
```json
{"duration": 60, "timing_source": "provider", "cues": [{"start": 0.2, "end": 3.1, "text": "你按下查詢之後，發生了什麼？"}]}
```
時間單位秒，cue 有正時長、按順序、不可重疊或超出音訊。`scripts/studio.py captions captions.json --out subtitles.srt` 驗證並輸出，不會產生配音或自動對時。

中文按語意斷句，避免拆開詞語；通常一到兩行，行長以目標畫面和字體實測。字幕與畫面重點字分層，字幕不要被生成進圖片。燒錄字幕保持可切換，另交 SRT。英文／數字混排要檢查，尤其 9:16。

先產 5–10 秒真實配音測試聲線與名詞，再決定是否整段生成。可將旁白分段快取；片段須用 scene id 對應，不能刪除失敗片段後讓後面聲音錯位。最後完整聽一次成片；若環境無法聽音訊，記錄為未聽驗，使用轉錄及音量工具作輔助但不宣稱等同聽驗。

配樂是選配，旁白優先。旁白時降低配樂音量；檢查削波、突變與音訊串流。字幕修字不一定重生成聲音；旁白內容改變則重做受影響音訊、字幕及下游時間軸。
