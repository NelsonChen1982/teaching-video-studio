# 先讓場景演出，再讓文字補充

## 從事件出發

每鏡先寫：誰／什麼物件，在何處，因為什麼而改變；觀眾將看見哪個前後差異。再寫運鏡與字幕。若答案只有「標題滑入、數字放大、圓點出現」，目前只有資訊排版，尚未完成影片場景。資料視覺化與文字動畫本身是使用者要求的主角時可成立，但不能擅自取代指定人物、實拍或 3D 敘事。

「高階學術教材」不等於論文封面、海報或課堂投影片。專業感優先來自內容正確、構圖、燈光、材質與可理解的動作。滿版場景預設不放常駐章節標題、頁碼、邊框、頁尾、裝飾線、進度條或英文眉標。必要字幕、定位標籤、資料來源或警示依內容保留；不要為了填留白新增文字。來源可放交付文件，不必每鏡印在畫面上。

## 角色與攝影機各自要做事

- 角色：身份與外觀連續；有動作準備、主動作和結果。人物可透過轉頭、目光、收手、後退、姿態與他人反應說明因果，不是全員原地上下浮動。
- 3D：近拍先檢查輪廓、五官、關節、衣物、材質差異和接地；不是把球柱加陰影就標成精緻人物。粗模只能用於構圖測試。必要時選有授權模型或外部生成素材，不能為趕渲染默默降級。
- 運鏡：相機在空間移動，有透視、視差、遮擋與主體連續性；整個畫面縮放不能冒稱 3D 運鏡。推近揭露反應、繞拍揭露關係、拉高揭露全貌；攝影機與角色不必一直動。
- 剪接：保持動作與觀看方向，按旁白轉折切鏡。結尾完成故事，不自動換成大字摘要卡。純切、同鏡延續都可優於特效。

## 交付前的藝術檢查

1. **主體檢查**：先判斷文字是否就是敘事主體。角色／物件事件可暫時隱藏字幕與標題，確認主體與變化仍可辨識；UI、精確圖解、動態字體則檢查操作因果、資訊層級與閱讀停留，不以「去掉文字便看不懂」否決。卡片、圖形與文字可作正式表現，不因先前影片失敗而一律禁止。
2. **畫格檢查**：近景、互動中景、全景各查必要代表幀。可見破面、穿模、幾何替身、不合要求的固定版面，不可因技術檢查通過而放行。
3. **時間檢查**：以正常速度觀看代表性動作與切換；確認不是靠字幕換行假裝故事前進。若工具只能查單幀，要坦白記錄此限制，不宣稱已完成動態觀賞驗收。
4. **要求對照**：在 QA 記錄每項可見證據及待解問題。使用者直接完成時自行完成以上檢查，不額外索取樣片批准；能力不足則具體說明。

## 回歸案例

需求：「30 秒直式，專業學術感，3D 小人、運鏡，沒有標頭標尾，保留已有配音。」

不合格：柱狀圖與圓點代替人群；全程大標題加頁碼；把 Canvas 叫成非 SVG 來辯護；只確認 MP4 規格或無瀏覽器錯誤。

可行方向之一：同一主角欲言又止 → 他人持續發言 → 周圍人物收回動作 → 鏡頭揭露更多沉默者。這只是因果敘事例子，不是每部影片都套用人群或同一種風格。
