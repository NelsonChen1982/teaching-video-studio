# 轉場是一個鏡頭交接的解答

先完成 DIRECTION.json，才選工具。候選依鏡頭關係和素材而生，不按風格名稱硬套。

| 關係／素材條件 | 可考慮的交接 | 必須檢查 |
|---|---|---|
| 同一流程、物件連續 | 同鏡跟拍、錨點 match、物件帶鏡 | 方位、大小、速度、因果是否連續 |
| 精確比較／狀態改變 | 對齊替換、分割畫面、硬切 | 差異能看見，沒有轉場混成第三種狀態 |
| 真實空間連續 | 平移、dolly、前景遮擋切 | 空間成立、物件不穿透、不暈眩 |
| 紙張／拼貼媒材成立 | 紙層滑移、翻頁、撕揭 | 厚度、遮擋、陰影、背景與字的歸屬 |
| 顏料／印刷行為成立 | 刷痕揭露、墨暈、壓印分色 | 邊緣結構、揭露方向、紙底一致 |
| 時間跳躍／章節 | 硬切、停頓、適當溶接 | 語意是否真需要同時看見 A 與 B |

這是候選語彙，不是風格選單。混合美術仍需一套一致的動作邏輯。

## 素材決定可行性

先標記 plate（含背景的完整畫面）／cutout（透明主體）／layers（分層素材）。兩張含不同紙底的完整圖，不能假裝共享一張紙。可以整幅替換或重新準備素材；不可用任意色鍵把白色物件一起挖掉。需要分層而沒有素材時，先請求／生成合適素材或選可用的交接。

## 防止無意重影

遮罩替換採 C=(1-M)A+MB，M 是空間變化的遮罩。不要同時把 A.opacity 與 B.opacity 全畫面慢慢交叉。只在遮罩窄邊界可有抗鋸齒／柔邊混合，已揭露區應完全由 B 取代。需要真實 dissolve 的鏡頭可明確選擇，不能一律禁止透明度。

字幕、流程標籤與全片底紋放獨立層；前後文字切換需定義，避免雙字幕。到 p=0 和 p=1 必須分別精確回到 A、B。若是遮擋式轉場，完全遮住時切底圖，再揭開，不能遮不滿就切。

## 內附原創遮罩元件

`assets/transitions/masks.mjs` 提供 dry-brush、ink-spread、directional-wipe 三個**技術元件**，不是風格預設或藝術品質保證。瀏覽器 demo 使用自行繪製的測試圖，不代表浮世繪或正式教材。

- `createField(width,height,{kind,seed})`：預先建立固定揭露順序，不能每幀新亂數。
- `maskAt(field,progress,feather)`：產出遮罩。預設 feather 是很窄的局部邊界；0 是硬邊。
- `compositeOpaque(a,b,mask,out)`：合成預先鋪好背景的兩張不透明 RGBA plate，輸出保持不透明；透明 cutout 需先組成 plate，不能直接餵入。

GSAP／HyperFrames 用時間推導 progress；Remotion 用 frame/fps。所有效果先測 endpoint、單調覆蓋、亂序 seek、透明混合面積，再用真實素材看動態。

## 樣片驗收

以起始、25%、50%、75%、完成與風險交接前後幀檢查；正常播放及慢放各看一次。記錄錯誤時間而非籠統說有質感。必須先確認 A/B 本身的美術品質，轉場不能救粗糙素材。固定素材可用灰階 matte 影片／影格序列做更精緻效果，但要檢查端點與授權。
