# 由風格與敘事推導效果

目的不是建立更多風格模板，而是讓 agent 作出有依據、可檢查的視覺決策。這裡的推導輸出是精簡的設計理由、證據與取捨，不是內部逐步思考全文。

## 1. 觀察，不靠名稱聯想

讀取老師的需求與每張參考，將可見證據和推測分開：線條／輪廓、形狀與比例、色彩、材質、構圖留白、文字。再記錄空間深度、光線、情緒、運動特性。只有風格名稱時先提出可驗證的 styleframe，不能假裝看過參考。

「可愛」不必然彈跳，「科技」不必然故障閃爍，「高級」不必然玻璃，「手繪」不必然畫筆描線，「日式」不必然潑墨。缺少支持時選節制且可理解的方式。

## 2. 把抽象偏好轉成製作條件

每項要落到可執行決定：
- 輪廓與形體 → 素材來源與建模細節、是否可用幾何圖。
- 材質 → 物件如何受力、揭露、遮擋、反光或變形。
- 構圖與深度 → 主焦點、鏡頭距離、2D/2.5D/3D、文字安全區。
- 情緒與受眾 → 速度、幅度、加減速、停留與次要動作。
- 教學目的 → 需要看見的因果／位置／狀態變化；動作是否幫理解。

先畫代表性靜態幀。造型、打光、字體和材質不及格就修畫面，不加轉場遮醜。既有 three-starter 僅是技術骨架，不是商業美術標準。需要物件近拍時增加可靠模型／結構、材質區別、接觸陰影與清楚構圖；做不到則縮小表現範圍或改成誠實的抽象圖解，不能宣稱已精緻化。

## 3. 由前後鏡頭關係選動作

每個交接先標記關係：continuation / cause-effect / comparison / location-change / time-jump / chapter-change。
- 同一物件或流程延續：先考慮保持同鏡、跟拍、構圖接續；不為換場切斷因果。
- 比較：對齊相同錨點、拆分視圖或狀態替換；轉場不可讓差異看不見。
- 空間改變：有連續場景才使用移鏡，否則用合理遮擋／切換，不能跨越不存在的空間。
- 時間跳躍／章節改變：硬切、停頓、媒材式翻頁等可清楚標記斷點。

## 4. 產生候選，再選擇

通常比較 2–3 個選項，至少包含一個低效果方案（直接切／不切／物件接續）。評估：教學清楚度、風格一致性、視覺連續性、素材是否支持、聲音節奏、實作與驗證成本。不要編造小數分數或以選項多寡充當推理。

記錄一個選擇理由及被捨棄候選的具體缺點。設計需新效果時可自行創作，附驗證計畫。只有存在相應媒材行為才採筆刷、紙張、液體等效果；不要固定「某風格→某效果」。

## 5. 先試最有風險的交接

先用真實素材做 styleframe 與短樣片；抽取轉場前、25%、50%、75%、轉場後和幾個邊界幀。確認兩個場景不是因透明度錯誤重疊、文字未重複、紙底無漂移、主體位置不跳、停留足夠。影格指標不能證明好看，必須視覺確認並正常速度觀看。

## 6. 根據結果調整

失敗時先判斷素材問題、構圖問題、動作問題或引擎問題，再改最相關部分。不要每次全部重生成，不把 renderer 換成 Remotion 當成自動提高美術品質。把教學、風格與技術驗證分開記錄。
